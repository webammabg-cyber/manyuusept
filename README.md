# LEKLAB — Laboratory Management System

Prototipe front-end LEKLAB yang dipisahkan menjadi HTML, CSS, dan JavaScript.

## File
- `index.html` — halaman utama
- `style.css` — tampilan dan responsivitas
- `app.js` — navigasi dan interaksi prototipe

## Menjalankan lokal
Buka `index.html` di browser. Tidak membutuhkan proses build.

## Publish ke GitHub Pages
1. Ekstrak ZIP ini.
2. Buat repository GitHub baru.
3. Upload `index.html`, `style.css`, dan `app.js` ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu simpan.

Catatan: data dan hasil pemeriksaan di versi ini adalah simulasi front-end. Aplikasi belum menggunakan backend/database dan bukan untuk menyimpan data medis nyata.
